# Steps to Clean GitHub Profile

Use this quick checklist to clean and focus your GitHub profile:

1. **Decide your core identity repos**  
   Pick 5–8 repositories that represent who you are now (for example: AI, backend, portfolio).

2. **Pin those repos**  
   On your GitHub profile, use **Customize your pins** and pin only your strongest current projects.

3. **Mark old school or throwaway repos**  
   Review your repositories list and mark projects you plan to remove, archive, or keep unpinned.

4. **Archive outdated repos**  
   For old projects you no longer maintain, open the repo → **Settings** → **Archive this repository**.

5. **Rename messy repos**  
   Rename unclear repository names to short, meaningful ones (for example: `pricesnap-backend`, `coding-agent`).

6. **Add short descriptions**  
   Add a one-line description to each kept repository, including what it does and the tech stack.

7. **Create topics/tags**  
   Add repository topics such as `ai`, `backend`, `android`, `portfolio` to improve discoverability.

8. **Write a simple profile README**  
   Include a short intro, a bullet list of top projects, and a link to your portfolio.

9. **Hide noise from pins**  
   Keep pinned repositories limited to high-quality, current work.

10. **Review once a month**  
    Revisit your profile monthly and unpin, archive, rename, or update repos as your focus changes.
